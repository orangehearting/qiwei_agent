# 剧本2 · 副场景：实验室泄漏秒切

> 定位：**快、反差、证明底座能复用**。30秒讲完，收口就是赢。
> 骨架已给你，`【】` 是你只需填一句真事的位。

---

## 三句话结构

1. **同一套传感器，换个语义。**
   在家，"温度高"是爷爷盖太厚了；在实验室，"温度高"是危化品柜在报警。
   场景换了，大脑的推理骨架没换——只是把"睡过头"翻译成了"需要应急"。

2. **应急 agent 自动抛预案。**
   检测到泄漏信号 → agent 不等人，直接按手册走：通风 → 撤离 → 上报，同时翻 RAG 危化品手册，把"该不该碰、往哪跑"递给现场的人。

3. **收口一句。**
   *"场景换了，大脑没换。"*

---

## 你的戏（只填一个真场景，秒切就成立）

你们实验室，**最怕哪种"出事"**？

- 是**酸类**？半夜漏了、挥发呛人？
- 还是**可燃物**，温度一高就怕？
- 还是**气体**，无色无味最阴？

【换你的真事】写下你最怕实验室发生的那件事，一句就够：
（代拟示范）最怕酸类夜间渗漏——无色无味，等人闻出来已经呛了眼。传感器得抢在鼻子前头先发现。

填了它，"秒切"就从抽象话术变成你亲口的底气。

---
> ⚠️ **教练如实注**：`（代拟示范）`那句是我按"多数实验室最怕酸类夜间渗漏"拟的通用版。请按你们实验室**真实最怕的那类事故**换一句——是酸、是可燃、还是无味气体？你对哪件事最发怵，就写哪件，秒切的底气才真。
