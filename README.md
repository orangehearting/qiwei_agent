# 栖卫 · 读懂空间的环境智能体

> **你不在的时候，谁替你看着爷爷奶奶？**

在我国，有近半数老人独自生活。他们的孙辈——像你我一样在外读书、打拼的人——最深的恐惧从来不是“不会说话”，而是“不知道”。不知道爷爷奶奶昨晚几点睡的，不知道今天有没有好好吃饭，不知道那个凌晨三点的起身，是正常起夜，还是一跤摔在客厅的地板上。

栖卫，是一只**会主动开口的空间智能体**。它被一双不需要摄像头的眼睛唤醒——温湿度、红外、门磁，这些不起眼的传感器铺陈在每个角落，静静读着家的呼吸。

它不是聊天助手，不会坐等被提问。**它自己发现问题，自己去找孙女说话**：当连续三夜睡眠时间悄悄后移，当白天活动量逐周下滑，当某天早晨房门异常迟开——它会推给家人一句“爷爷这两天活动和前两周有点不一样，最近是不是没睡好？建议留意，必要时联系社区医生”。话里始终带着那句不变的红线：**提醒，不是医嘱**。

把一天的碎片，沉淀成一周的画像；把一周的沉默，翻译成一句人话。这是规则引擎永远做不到的温柔，是普通设备给不了的记性。

而栖卫的野心不止于此。**同一副大脑，换一身皮肤，就是另一座守护者**——把它接进实验室，它就是危化品安全应急员，嗅到异常自动抛出处置预案。一个底座，两个战场。守护家人，也守护每一间正在运转的房间。

## 架构

```text
┌──────────────────────────────────────────────────────────┐
│               栖卫 · 环境智能体底座                     │
│                一个大脑，两个战场（统一推理核心）              │
└──────────────────────────────────────────────────────────┘

传感器层     温湿度 │ 红外 │ 门磁          (ESP32 真设备 / MQTT)
              │
接入层        FastAPI 接收 ─────────────────────► 入库
              │
大脑层    LangGraph Supervisor 路由，多专家 Agent
              [ 睡眠 │ 活动 │ 出入 │ 风险 │ 关怀文案 ]
              │
       ┌───────────────┴───────────────┐
       ▼                                ▼
 记忆 + 趋势画像                 主动关怀触发器
 (thread_id 住户归档 │ 日/周画像   (定时 + 事件双源)
  │ checkpoint+向量)                │
       │                             ▼
       ▼                     MCP 通知 Agent
  RAG 知识库                  (微信 / 企业微信)
  (健康照护 │ 危化品)

场景皮肤 ── 主：居家养老守护        副：实验室安全
              │                      │
              主动关怀+周报             危化品事件→应急预案

家属端 / 机构屏   Vue 面板 · 今日报告 · 趋势图 · 对话
```

## 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 传感器 | ESP32 + 温湿度/红外/门磁 | 实验室白嫖、插电即用 |
| 通信 | MQTT broker | 物联网标准，轻量低耗 |
| 接入 | FastAPI | 已会，包 HTTP/WebSocket |
| 大脑 | LangGraph + Supervisor | 已会，多专家路由 |
| 记忆 | thread_id + checkpoint + 向量库 | 已会，白捡多租户 |
| 知识库 | RAG（text-embedding-v3) | 已会，语义检索 |
| 通知 | 自写 MCP server（微信 webhook）| 已会，主动关怀闭环 |
| 前端 | Vue + ECharts 趋势图 | 教练给壳 |
| 部署 | Docker Compose | 一键演示 |

> **一则**：一个大脑、两个战场、三种记忆（日/周/长周期）、一道红线（提醒非医嘱）。
